# AviControl · Frontend del Módulo 1

Interfaz web (React + TypeScript + Vite) que consume la API REST `/api/v1` del Módulo 1.
Tecnologías, alcance, estructura y reglas: [arquitectura.md, sección Frontend](../avicontrol/docs/arquitectura/arquitectura.md#frontend).

```bash
npm install
npm run dev            # http://localhost:5173 con la API simulada (MSW)
npm run dev:backend    # contra el backend real en http://localhost:8080
npm test
npm run build
```
